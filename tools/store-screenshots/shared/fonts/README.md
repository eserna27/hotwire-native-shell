# Fonts

Webfonts used by the Portada template. `store/brand.yml` chooses the family names (`display`, `sans`, `mono`, `ui`). The files are the Google Fonts builds of Bodoni Moda, Archivo, IBM Plex Mono, Inter, and the other families named in `fonts.css`.

Those upstream fonts are under the SIL Open Font License or the Apache License 2.0. This directory redistributes the font files with the template so a render does not fetch them.
